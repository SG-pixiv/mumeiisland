# 무명섬 디스코드 봇

내전 디스코드 서버에서 쓰는 봇이에요. 무명섬 DB(Supabase)에 바로 읽고 써요.

| 명령어 | 누가 | 하는 일 |
| --- | --- | --- |
| `/연결 게임닉네임` | 누구나 | 내 디스코드 계정을 무명섬 선수와 연결 요청 → 웹 관리자 대시보드에서 승인 |
| `/연결해제` | 누구나 | 내 연결 풀기 (대기 중인 연결 요청도 취소) |
| `/내정보` | 누구나 | 연결된 선수 · 티어 · 솔로 랭크 점수 · 신청한 내전 |
| `/참가` · `/참가취소` | 연결된 선수 | 내전 참가 신청 · 취소 (내전을 안 고르면 가장 가까운 내전) |
| `/내전공지` | 운영진 | 이 채널에 [참가하기] [참가 취소] 버튼이 달린 공지. "예정" 내전은 "참가 모집 중"으로 바뀌어요 |
| `/소개공지` | 운영진 | 무명섬 소개 공지를 이 채널에 올려요. 창이 뜨면 제목 · 내용을 고쳐서 보내기. 큰 그림(`public/welcome.png`) + 사이트로 가는 버튼 5개(바로가기 · 일정 · 기록 · 선수 · 규칙). 디스코드는 그림을 링크로 못 만들어서 제목과 버튼을 누르면 사이트로 가요 |
| `/mvp 시작` · `/mvp 마감` `[내전] [라운드]` | 운영진 | **라운드 MVP** 투표를 손으로 열기(다시 열기) · 바로 마감. 보통은 결과를 확정하면 자동으로 열리고 30분 뒤 자동 마감돼요. 최다 득표가 그 라운드 MVP, 공동 1위면 추첨 (DB 9단계 필요) |
| `/채널설정 공지·명령어·명령어해제·보기` | 운영진 | 공지 · 알림 채널과 명령어 채널 정하기 (아래 "채널 나누기") |
| `/관리자키 [@유저]` | 운영진 | 무명섬 웹 관리자 키 (24시간 · 1회용). 유저를 고르면 그 사람 계정 전용 키를 DM 으로 보내요 (DM 이 막혀 있으면 나에게 보여 줘요). 비우면 나 |
| `/관리자목록` | 운영진 | 지금 무명섬 관리자와 안 쓴 키 개수 |
| `/관리자추가 @유저` | 무명섬 소유자 · 공동 소유자 | 키 없이 바로 무명섬 관리자로. 유저 칸에서 `@` 로 서버 멤버를 골라요 (숫자 ID 를 칠 필요 없어요). 사이트에 로그인한 적 있으면 바로, 없으면 그 계정으로 처음 로그인할 때 관리자 화면이 열려요. 운영진 명령어는 추가한 순간부터 돼요 (DB 8단계 필요) |
| `/관리자해제 @유저` | 무명섬 소유자 · 공동 소유자 | 그 사람을 웹 관리자에서 바로 빼고, 남은 키 · 로그인 전 추가도 취소 (소유자는 못 빼요. 공동 소유자는 소유자만 빼요) |

**운영진** = 디스코드 서버 관리자 **또는** 무명섬 관리자(웹 권한 관리 · `/관리자추가` 로 추가한 사람). 그래서 서버 관리자 권한이 없거나 빠져도 무명섬 관리자면 운영진 명령어를 다 쓸 수 있어요.

- 답장은 대부분 **나만 보이게** 와요. 공지 · 투표 · MVP 발표 · 라운드 결과만 **공지 채널**에 올라가요.
- **참가 공지 자동 게시**: 웹 일정 관리에서 상태를 **참가 모집 중**으로 저장하면 30초 안에, 그리고 **시작 24시간 전**에 한 번 더 공지 채널에 참가 공지가 올라가요. 시작이 24시간도 안 남았을 때 모집 중이 되면 한 번만 올라가고, `/내전공지` 로 이미 올렸으면 그걸로 쳐요. 확정 내전은 24시간 전 알림만, 예정 내전은 안 올라가요. 일정을 옮기면 새 시작 시각 기준으로 다시 알려요. 새 공지가 올라가면 예전 공지의 버튼은 떼요.
- **내전을 지우면 메시지도 정리**: 웹 일정 관리에서 내전을 삭제하면 그 내전에 봇이 올린 참가 공지(하루 전 공지 포함) · MVP 투표 · MVP 발표 · 라운드 결과 메시지를 30초 안에 지워요. 봇이 올린 메시지를 `bot/data/settings.json` 에 기억해 두고, 내전이 DB 에서 정말 없어졌는지 한 번 더 확인한 다음 지워요. 이 기능 전에 올린 것 중에는 지금 살아 있는 참가 공지 · 투표 메시지만 기억하고, 이미 지운 내전의 메시지는 손으로 지워 주세요.
- **라운드 MVP 자동 투표**: 결과 검토에서 라운드를 확정하면 결과 공지 바로 아래에 그 라운드 MVP 투표가 열려요. 후보는 그 판에 뛴 무명섬 선수, 투표는 내전 참가자 · 그 판 선수만(자기 자신 X, 마감 전까지 바꾸기 O). **30분 뒤 자동 마감** → MVP 발표를 올리고 투표 메시지는 지워요. 아무도 안 찍으면 MVP 없이 닫혀요. 다시 확정해도 투표는 다시 안 열려요. OBS 오버레이에는 MVP 를 안 띄워요.
- **내전 끝 정리**: 내전이 끝나면(상태 완료 · 예정 라운드를 다 확정하고 투표도 끝 · 시작 12시간 뒤 중 먼저) 참가 공지와 투표 메시지를 지워요. 라운드 결과와 MVP 발표는 남겨요.
- **라운드 결과 자동 공지**: 웹 결과 검토에서 확정하면 30초 안에 공지 채널에 순위 · 점수 · 누적 순위가 올라가요. 확정 취소 후 다시 확정하면 "(수정됨)"으로 다시 올라가요.
- 공지 인원과 투표 수는 버튼을 누를 때마다, 그리고 3분마다(웹에서 바꾼 것까지) 다시 그려져요.
- 봇은 디스코드로 나가는 연결만 써서 서버에 포트를 열 필요가 없어요.

## 처음 한 번 설치하기

### 1. 무명섬 DB 준비 (6단계 SQL)
Supabase → SQL Editor 에 `supabase/migrations/20261028080000_discord_bot.sql` 을 통째로 붙여 넣고 Run → "디스코드 봇 준비 완료" 가 나오면 끝.

### 2. 디스코드 개발자 포털 (로그인에 쓰는 그 무명섬 앱)
https://discord.com/developers/applications → 무명섬 앱
1. **General Information** → `Application ID` 복사 → `DISCORD_APP_ID`
2. **Bot** → **Reset Token** → 나온 토큰 복사 → `DISCORD_TOKEN` (한 번만 보여요. 절대 공유 금지)
   - Privileged Gateway Intents 는 **전부 꺼 둬도** 돼요
   - 다른 사람이 봇을 초대하지 못하게 **Public Bot** 은 꺼 두는 걸 추천해요
3. 아래 주소의 `앱ID` 를 바꿔서 열고 → 내전 서버 고르기 → 승인 (봇 초대)
   ```
   https://discord.com/oauth2/authorize?client_id=앱ID&scope=bot%20applications.commands&permissions=84992
   ```
   (권한: 채널 보기 · 메시지 보내기 · 링크 첨부 · 메시지 기록 보기)
4. 디스코드 앱 → 설정 → **고급** → 개발자 모드 켜기 → 내전 서버 이름 우클릭 → **서버 ID 복사** → `DISCORD_GUILD_ID`

### 3. Supabase 비밀 키
Supabase → Project Settings → **API Keys** → Secret keys 의 `sb_secret_...` 복사 → `SUPABASE_SECRET_KEY` (절대 공유 금지)

### 4. 오라클 서버에 설치
SSH 로 접속해서 (Ubuntu 기준)
```bash
# Node.js 22 (이미 있으면 건너뛰기: node -v 가 v20.6 이상이면 OK)
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs git

# 코드 받기
git clone https://github.com/SG-pixiv/mumeiisland.git
cd mumeiisland/bot
npm ci

# 설정 파일 만들고 2 · 3 에서 복사한 값 넣기 (nano: 저장 Ctrl+O → Enter, 나가기 Ctrl+X)
cp .env.example .env
nano .env

# 슬래시 명령어 등록 (명령어 13개를 등록했어요 가 나오면 OK)
npm run register

# 시험 실행 → "무명섬 봇 켜짐" · "무명섬 DB 연결 OK" 가 나오면 Ctrl+C 로 끄기
npm start
```
> Oracle Linux 라면 첫 두 줄 대신 `sudo dnf module install -y nodejs:22 && sudo dnf install -y git`

### 5. 계속 켜 두기 (pm2)
```bash
sudo npm install -g pm2
pm2 start npm --name mumei-bot -- start
pm2 save
pm2 startup        # 나온 sudo ... 줄을 그대로 복사해서 한 번 실행 (서버가 재부팅돼도 자동으로 켜져요)
```
예전 픽시브 봇이 같은 서버에 있어도 같이 돌아가요. 무명섬 관리자 **대시보드 → 연동 상태 → 디스코드 봇** 이 "켜짐" 이면 성공이에요.

## 채널 나누기 (추천)
| 채널 | 누가 글을 써요 | 올라가는 것 |
| --- | --- | --- |
| 📢 공지 · 알림 (예: `#내전-공지`) | 봇만 | 내전 공지([참가하기] 버튼), MVP 투표 · 발표, 라운드 결과 |
| ⌨️ 명령어 (예: `#봇-명령어`) | 누구나 | `/연결` `/연결해제` `/내정보` `/참가` `/참가취소` |

1. 디스코드에서 두 채널을 만들어요
2. **공지 채널** 설정(톱니) → 권한
   - `@everyone`: **메시지 보내기 · 애플리케이션 명령 사용 끄기** (버튼 · 투표 메뉴는 그래도 눌러져요)
   - **무명섬 봇**(멤버나 역할로 추가): 채널 보기 · 메시지 보내기 · 링크 첨부 · 메시지 기록 보기 **허용**
3. 공지 채널에서 `/채널설정 공지`, 명령어 채널에서 `/채널설정 명령어` (채널을 안 고르면 지금 채널)
4. `/채널설정 보기` 로 확인. 명령어 채널 제한을 없애려면 `/채널설정 명령어해제`

- 관리자 명령어(`/내전공지` · `/mvp` · `/관리자키` …)는 어느 채널에서 쳐도 결과는 공지 채널로 가요
- 설정은 서버의 `bot/data/settings.json` 에 저장돼요. 진짜 서버로 옮기면 그 서버에서 `/채널설정` 을 다시 해 주세요
- 공지 채널을 안 정하면 명령어를 친 채널에 올라가고, **라운드 결과 자동 공지는 꺼져 있어요**

## 자주 쓰는 명령어 (서버에서)
```bash
pm2 logs mumei-bot          # 로그 보기 (나가기 Ctrl+C)
pm2 restart mumei-bot       # 다시 켜기
pm2 status                  # 켜져 있는지

# 새 버전 받기
cd ~/mumeiisland && git pull && cd bot && npm ci && npm run register && pm2 restart mumei-bot
```

## 내전 날 흐름
1. 운영진: 웹 일정 관리에서 내전 만들기 → 디스코드 공지 채널에서 `/내전공지`
2. 참가자: 처음 한 번 `/연결 게임닉네임` → 운영진이 웹 대시보드에서 **승인** → [참가하기] 버튼
3. 운영진: 웹 팀 편성 · 드래프트 → 게임 → 결과 검토에서 확정
   → 확정할 때마다 공지 채널에 라운드 결과가 자동으로 올라가요
4. 운영진: `/mvp 시작` → 참가자 투표 → `/mvp 마감` → MVP 발표 (웹 내전 기록에도 표시)

## 문제가 생기면
- **명령어가 안 보여요**: `npm run register` 를 다시 하고, `DISCORD_GUILD_ID` 가 내전 서버 ID 인지 확인. 디스코드 앱을 껐다 켜면 바로 보여요
- **"이 채널에 글을 쓸 권한이 없어요"**: 그 채널 설정 → 권한에서 봇(또는 봇 역할)에 메시지 보내기 · 링크 첨부 허용
- **로그에 "무명섬 DB 에 연결하지 못했어요"**: `SUPABASE_URL` · `SUPABASE_SECRET_KEY` 확인, 6단계 SQL 실행 여부 확인
- **"디스코드 로그인 실패: DISCORD_TOKEN 이 틀렸어요"**: 개발자 포털 → Bot → Reset Token 으로 새로 받아 `.env` 에 넣고 `pm2 restart mumei-bot`
- **운영진 명령어가 일반 멤버에게도 보여요**: 정상이에요. 서버 관리자가 아니어도 무명섬 관리자면 쓸 수 있게 목록은 다 보이고, 운영진이 아니면 봇이 "운영진만 쓸 수 있어요"로 거절해요. 숨기고 싶으면 디스코드 서버 설정 → 연동 → 무명섬에서 명령어마다 보일 역할을 정하면 돼요
