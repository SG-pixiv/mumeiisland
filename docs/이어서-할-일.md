## 3. 무명섬

### 3-1. SG가 정한 것
- 공개 페이지는 누구나 보고, 쓰기는 관리자만. 디자인: 기본색 `#f880b9`, 포인트색 `#8fdff5`, 귀여운 느낌, 헤더 "무명섬" 은 글자별로 기울인 테두리 글씨. **기존 디자인을 해치지 않게** 추가만 해요.
- 내전은 2주마다. 한 팀 3명 = **1티어 팀장 1명 + 2 · 3티어 아무나 2명** (2 · 3티어는 표시만, 편성 때는 구분 없음).
- 티어(1~3)는 관리자만 정해요. 자동 편성 밸런스는 솔로 랭크 점수 합 기준 (티어는 자동으로 안 바뀜).
- 드래프트(포인트 없음): 첫 바퀴는 지난 내전 꼴찌 팀장부터, 둘째 바퀴는 1등 팀장부터. 관리자 한 명이 입력.
- 점수: 이터널 리턴 공식 대회 규정 (킬 1점 · 1~2일차 0.5점, 순위 10 · 7 · 5 · 4 · 3 · 2 · 1 · 0, 처치자 불명 사망 −1 — 야생동물 · 금지구역 포함). 체크포인트 없이 합계만. 사용자 설정 대전은 이리 API 에 기록이 없어서 딜량은 안 써요.
- 결과 입력: 게임 PC 업로드 프로그램이 게임의 "데이터 저장" CSV 를 자동으로 올리고, 관리자가 결과 검토에서 확정.
- 관리자: SG가 디스코드 서버에 못 들어갈 수도 있어서 **키 방식**(소유자 설정 키 → 관리자 키) + 바로 추가 + 공동 소유자.
- MVP 는 라운드마다 디스코드 투표 (최다 득표, 공동 1위면 추첨).
- 경쟁 기록은 처음에 **비공개**, 관리자가 "기록 공개"에서 켜요. 시즌 대신 회차.

| 스킬 칸(`type_bgs`)에 흰 줄 · 홈 | 9조각으로 늘려 쓰는 그림이라 글자 · 모서리 깎기를 넣으면 늘어나요 → 무늬 없는 판으로 (11-08) |
| `getDexNumber` 를 ER 번호로 바꿀 때 순환 가져오기 걱정 | `roster.ts` 의 `erCodeOfSpecies` 만 가져와요. 문제 없었어요 |
| 이름 "Guest" 를 바꾸면 저장이 사라질 수 있음 | "Guest" 는 저장 키(`data_Guest` 등)라 그대로. 화면에만 `displayUsername()` 으로 "생존자" |
| 시트 명중을 100 아래로 하면 `play.test.ts` 50웨이브 검사가 1웨이브에서 400턴 맴돎 | 검사 난수가 빗나가는 쪽으로 굴러요 → 그 검사에서만 몸통박치기 `calculateBattleAccuracy` 를 -1 로 (11-09) |
| 게임 안 기술 숫자로 포켓몬 예시를 뽑으면 틀림 | 실험체 스킬로 빌려 쓴 기술은 시트 값으로 바뀌어 있어요 → `draft_examples.py` 는 `move.ts` 원래 숫자를 직접 읽어요 |
| 변화 ↔ 공격은 시트로 못 바꿈 | 위력 · 명중 · PP · 선공 · 물리↔스증만 덮어써요 (`hooks.ts` 의 `applySheetSkill`). 바꾸려면 빌릴 기술 자체를 바꿔요 |
| Sheets 문서 종류가 없음 (Artifact 종류 목록에 Docs · Slides · Design · Dashboard · Design System 만) | 표는 `.xlsx` 로 만들어 보내고 저장소 `docs/sheets/` 에도 넣어요 |
| `biome check --write src/ui/handlers/*.ts` 처럼 넓게 돌리기 | 다른 파일까지 고칠 수 있어요. 돌린 뒤 `git status` 로 내가 고친 파일만 바뀌었는지 봐요 |
| 다른 작업과 같은 문서를 동시에 고쳐서 push 가 거절됨 (11-09) | `git pull --rebase` (다른 부분이면 저절로 합쳐져요). 겹치면 둘 다 살려서 합치고, 남이 쓴 내용은 지우지 않아요 |
| 작업 공간 git 이 일부 브랜치만 받아 와서 `origin/<브랜치>` 가 없다고 나옴 | `git config --add remote.origin.fetch '+refs/heads/*:refs/remotes/origin/*'` → `git fetch` |
| 무명섬 "애플리케이션이 응답하지 않았습니다" (11-08) | 인원 제한이 아니라 봇 꺼짐 · 서버 멈춤이에요 → 3-10 순서대로. 서버 로그 시각은 영국 시간(UTC), 봇 로그는 한국 시간 |
