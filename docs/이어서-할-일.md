## 3. 무명섬

### 3-1. SG가 정한 것
- 공개 페이지는 누구나 보고, 쓰기는 관리자만. 디자인: 기본색 `#f880b9`, 포인트색 `#8fdff5`, 귀여운 느낌, 헤더 "무명섬" 은 글자별로 기울인 테두리 글씨. **기존 디자인을 해치지 않게** 추가만 해요.
- 내전은 2주마다. 한 팀 3명 = **1티어 팀장 1명 + 2 · 3티어 아무나 2명** (2 · 3티어는 표시만, 편성 때는 구분 없음).
- 티어(1~3)는 관리자만 정해요. 자동 편성 밸런스는 솔로 랭크 점수 합 기준 (티어는 자동으로 안 바뀜).
- 드래프트(포인트 없음): 첫 바퀴는 지난 내전 꼴찌 팀장부터, 둘째 바퀴는 1등 팀장부터. 관리자 한 명이 입력.
- 점수: 이터널 리턴 공식 대회 규정 (킬 1점 · 1~2일차 0.5점, 순위 10 · 7 · 5 · 4 · 3 · 2 · 1 · 0, 처치자 불명 사망 −1 — 야생동물 · 금지구역 포함). 체크포인트 없이 합계만. 사용자 설정 대전은 이리 API 에 기록이 없어서 딜량은 안 써요.
- 결과 입력: 게임 PC 업로드 프로그램이 게임의 "데이터 저장" CSV 를 자동으로 올리고, 관리자가 결과 검토에서 확정.
- 관리자: SG가 디스코드 서버에 못 들어갈 수도 있어서 **키 방식**(소유자 설정 키 → 관리자 키) + 바로 추가 + 공동 소유자.
- MVP 는 라운드마다 디스코드 투표 (최다 득표, 공동 1위면 추첨).
- 경쟁 기록은 처음에 **비공개**, 관리자가 "기록 공개"에서 켜요. 시즌 대신 회차.

### 3-5. 자동 작업
- `er-sync` (이리 API 동기화): 매일 05:00 (크론 `er-sync-daily`), 한 번에 최대 40명. 닉네임이 바뀌면 점수를 지우지 않고 알려 줘요 (이리 UID 는 닉네임마다 새로 생김).
- `live-sync` (치지직 · 유튜브 LIVE): 2분마다 (크론 `live-sync`). 치지직은 비공식 공개 주소라 막히면 20분 뒤 LIVE 를 숨겨요. 유튜브는 RSS 우선 (쿼터 하루 약 720).
- `upload-result`: 업로드 프로그램 → 결과 검토. gameId 나 CSV 내용이 같으면 같은 게임으로 막아요.
- Supabase 무료 플랜은 한 달 받는 양(egress) 5GB 라서 화면에 쓰는 칸만 받아요 (README 22번). 새 화면도 `select` 에 쓰는 칸만 적어요.

## 5. 앞 작업에서 겪은 함정

| 생긴 일 | 해결 |
|---|---|
| 테스트(가짜 Phaser)에서 `input.on` 이 없어서 멈춤 | `mouseController.init()` 에서 없으면 건너뜀 |
| 설정 화면이 클릭을 전부 무시 (컨테이너가 interactive) | 직접 누르기 처리가 있는 오브젝트(pointerdown/pointerup)일 때만 원래 게임에 맡김 |
| 고르기 목록 커서와 칸이 어긋남 | 한국어 글꼴 줄 간격 → `getRowPitch` · `getOptionPitch` |
| 보상 화면 빈 곳 클릭이 보상을 가져감 | 빈 곳 클릭은 대사 창이 기다릴 때만 |
| 마우스 올리기로 튜토리얼이 떠서 자동 확인이 멈춤 | 기다리기 도우미 + 튜토리얼 중 올리기 무시 |
| 개발 서버가 새로 고쳐져 브라우저 확인이 끊김 | 따로 빌드 + `python3 -m http.server` |
| Vercel 첫 빌드 실패 (`dist` 없음) | `2d9fd66` 에서 고침 |
| `.gitignore` 의 `er-data/` 가 `scripts/er-data/` 까지 뺌 | 받은 데이터 폴더만 빼게 고침 |
| 노트북 파일을 못 봄 | 작업이 연결된 컴퓨터(데스크톱)만 보여요. 노트북 Claude 앱에서 새 작업을 시작해야 노트북에 연결돼요 |
